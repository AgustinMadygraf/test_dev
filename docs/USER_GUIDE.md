# 🔑 Manual de Usuario

¡Bienvenido al Sistema de Gestión de Expedientes! Seguí estos pasos para empezar a usarlo:

## 1. Registro de Usuario
- Entrá a "Regístrate aquí" desde la pantalla de inicio o directo a /register.
- Poné tu nombre completo, un correo válido y una contraseña.

## 2. Inicio de Sesión
- Identificate con tu correo y contraseña en la pantalla de /login.
- Cuando ingreses, el sistema te mantiene la sesión activa con un token de seguridad.

## 3. Gestión de Expedientes
Una vez que estés en el panel principal:
- **Crear:** Completá el formulario con el número de expediente y un extracto. La descripción es opcional.
- **Consultar:** Vas a ver una tabla con tus expedientes. **Ojo:** Por seguridad, no vas a poder ver expedientes de otros.
- **Detalles:** Hacé clic en el botón de información para leer la descripción extendida.

## 4. Cerrar Sesión
- Hacé clic en "Cerrar Sesión" arriba a la derecha para salir seguro.
