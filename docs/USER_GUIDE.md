# 🔑 Manual de Usuario

Bienvenido al Sistema de Gestión de Expedientes. Sigue estos pasos para comenzar:

## 1. Registro de Usuario
- Accede a la opción **"Regístrate aquí"** desde la pantalla de inicio o ve a `/register`.
- Ingresa tu nombre completo, un correo válido y una contraseña.

## 2. Inicio de Sesión
- Identifícate con tu correo y contraseña en la pantalla de `/login`.
- Al ingresar, el sistema mantendrá tu sesión activa mediante un token de seguridad.

## 3. Gestión de Expedientes
Una vez en el panel principal:
- **Crear:** Completa el formulario con el número de expediente y un extracto. La descripción adicional es opcional.
- **Consultar:** Verás una tabla con tus expedientes. **Nota:** Por seguridad, no podrás ver expedientes creados por otros usuarios.
- **Detalles:** Haz clic en el botón de información para leer la descripción extendida de un registro.

## 4. Cerrar Sesión
- Haz clic en el botón **"Cerrar Sesión"** en la parte superior derecha para salir de forma segura.
