# Sistema de Gestión de Expedientes

Este proyecto es una aplicación web para la gestión de expedientes, desarrollada como parte de una evaluación técnica.

## Certezas del Proyecto

- **Framework:** FastAPI.
- **Base de Datos:** MySQL.
- **ORM:** SQLAlchemy.
- **Entidad Principal:** Expedientes (Gestión de registros).

## Requerimientos Implementados

1. **Autenticación:** Sistema de Login funcional.
2. **Endpoints API-REST:**
   - Al menos un endpoint de lectura (GET) para consultar expedientes.
   - Al menos un endpoint de escritura (POST/PUT) para crear o modificar expedientes.
3. **Frontend:** Interfaz básica (Home) utilizando HTML, CSS y JavaScript.
4. **Infraestructura:** Soporte para despliegue mediante Docker y Docker Compose.
5. **Calidad:** Cobertura de tests unitarios para los endpoints principales.

*Nota: El detalle técnico de instalación y uso se completará al finalizar el desarrollo.*
